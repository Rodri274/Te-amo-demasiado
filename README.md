# Lo que comenzó contigo 💙

Una página personal hecha para recordar nuestro primer beso y nuestro primer cenote juntos.

## Publicarla con GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo, `para-ti`).
2. Sube **todo el contenido de esta carpeta** a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama **main**, la carpeta **/(root)** y pulsa **Save**.
6. En unos minutos estará disponible en `https://TU-USUARIO.github.io/para-ti/`.

El sitio no usa librerías ni servicios externos: sólo HTML, CSS y JavaScript. Funciona directamente en GitHub Pages.
